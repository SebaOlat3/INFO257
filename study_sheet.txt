Resumen: conceptos clave para la interrogación

Conceptos:
- Dataset / DataFrame: Contenedor de los datos crudos; filas = ejemplos, columnas = características y etiqueta.
- Features (X): Variables de entrada que usa el modelo (ej.: HP, Attack).
- Target (y / Legendary): Variable objetivo a predecir (0/1).
- Train / Valid / Test: Entrenamiento (ajustar parámetros), validación (ajustar hiperparámetros / early stop), prueba (evaluación final).
- stratify: Mantiene proporción de clases al dividir (importante en datasets desbalanceados).
- StandardScaler: Normaliza features a media 0 y varianza 1; ayuda a convergencia de la red.
- Dataset personalizado (torch.utils.data.Dataset): Envuelve datos para convertirlos en tensores y exponer __len__/__getitem__.
- DataLoader: Crea minibatches, controla batch_size y shuffle.
- batch_size: Número de ejemplos por paso de optimizador; afecta estabilidad y memoria.
- optimizer (ej. Adam): Algoritmo que actualiza pesos; Adam es adaptativo y robusto por defecto.
- learning rate (lr): Tamaño del paso en la actualización; hyperparámetro crítico.
- CrossEntropyLoss: Pérdida para clasificación con logits y múltiples clases.
- model.train()/model.eval(): Modo entrenamiento activa dropout/batchnorm; eval() desactiva comportamiento de entrenamiento.
- torch.no_grad(): Desactiva cálculo de gradientes en evaluación para ahorrar memoria/tiempo.
- Dropout: Regularización que apaga neuronas aleatoriamente para reducir overfitting.
- Early stopping / best checkpoint: Guardar modelo con mejor validación para evitar sobreajuste.
- Precision / Recall / F1: Métricas para evaluar clasificación en datasets desbalanceados.
- Confusion matrix: Muestra TP, TN, FP, FN; útil para entender tipo de error.
